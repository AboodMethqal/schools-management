# مثقال تك | Methqal Tech

منصة مدرسية متكاملة لإدارة المدرسة والطلاب والمعلمين وأولياء الأمور والمحاسبة.

## الأدوار
- المدير العام للمنصة
- مدير المدرسة
- المعلم
- الطالب
- ولي الأمر
- المحاسب

## أهم الوحدات
- إدارة المدارس والمستخدمين
- الطلاب والمعلمون والفصول والشعب والمواد
- الحضور والغياب
- الاختبارات والنتائج وبنك الأسئلة
- الواجبات والمواد التعليمية
- تقييم الأداء والملاحظات السلوكية والأكاديمية
- بوابة ولي الأمر مع دعم ربط أكثر من طالب بالحساب نفسه
- الإعلانات والإشعارات والتواصل
- الرسوم والمدفوعات وسجل التحصيل
- التقارير والتحليلات والرسوم البيانية
- الاشتراكات وإدارة المدارس للمدير العام
- الدعم الفني وتذاكر المساندة

## التقنية
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Prisma + PostgreSQL
- Supabase Auth
- Recharts
- Framer Motion

## اللغات والواجهة
العربية هي اللغة الافتراضية، مع دعم كامل للتبديل إلى الإنجليزية من زر اللغة في الهيدر. اتجاه الواجهة يتبدل تلقائيًا بين RTL وLTR.

## التشغيل
1. `npm install`
2. أنشئ `.env.local` بالقيم المطلوبة لـ Supabase وPostgreSQL.
3. `npx prisma generate`
4. `npx prisma migrate deploy`
5. شغّل `npm run dev`

## النشر
التطبيق مبني على Next.js ويمكن نشره على Vercel، مع PostgreSQL/Supabase كطبقة البيانات.

## ملاحظات قبل الإنتاج
- ضبط مفاتيح البيئة الحقيقية.
- تطبيق migration الخاصة بربط ولي الأمر بأكثر من طالب.
- مراجعة RLS والصلاحيات لكل دور.
- إنشاء حسابات وتجهيز بيانات المدرسة الحقيقية.
- ربط مزود دفع محلي/إقليمي إذا كانت المدرسة تحتاج دفعًا إلكترونيًا؛ النظام الحالي يسجل طلبات الدفع داخليًا ولا يعتمد على مزود دفع أجنبي.
- اختبار جميع الصفحات على الهاتف والكمبيوتر باللغتين.
- تشغيل `npm run build` بعد تثبيت الحزم وتوليد Prisma Client.
